家庭游戏盒 — 部署说明 (Windows / Linux / macOS)
==========================================================

zip 根目录解压后:
  app/                         FastAPI 应用（uvicorn app.main:app）
  web/                         大厅与游戏静态页
  requirements.txt
  family-product.json, INSTALL.txt
  install.bat / install.sh
  service.bat / service.sh
  scripts/                     各平台底层脚本

默认端口: 18029
Python: 3.10+（install 自动选版本并建 .venv）
本期无 Agent Skill / MCP

健康检查: GET http://127.0.0.1:18029/api/v1/health
大厅:     GET http://127.0.0.1:18029/game-box/
应用前缀: /game-box（可用环境变量 ROOT_PATH 修改；设为空则挂在站点根）
反代应将 /game-box 原样转发到本服务，不要剥前缀。
Windows 计划任务: FamilyGameBox
launchd (macOS): com.family.smart.game-box
Linux systemd user: family-game-box.service

======================================================================
服务维护
======================================================================

  install / start / stop / restart / status / uninstall
  Windows: service.bat <action>
  Unix:    ./service.sh <action>

  快捷: install.bat  或  ./install.sh

======================================================================
Windows
======================================================================

1. 解压 family_game_box.zip
2. cd family_game_box
3. service.bat install
4. http://127.0.0.1:18029/

======================================================================
Linux / macOS
======================================================================

1. unzip -d ~/family_game_box && cd ~/family_game_box
2. chmod +x *.sh scripts/*.sh scripts/lib/*.sh
3. ./service.sh install
4. Linux 自启: loginctl enable-linger $USER

======================================================================
打包
======================================================================

  整盒: scripts\build_and_pack.bat 或 ./scripts/build_and_pack.sh
        → dist_out/family_game_box.zip（含全部内置游戏）

  单游戏: scripts\pack_game.bat <id> 或 ./scripts/pack_game.sh <id>
          → dist_out/games/<id>.zip（管理页上传，热更新无需重启）

  说明: docs/game-packages.md（game.json、上传/启停、每日与难度）
