# 舒尔特挑战 — 设计

**日期:** 2026-08-25  
**状态:** 已确认  

## 1. 目标

将 `web/games/schulte/index.html` 从占位改为可玩的舒尔特方格；支持休闲 / 挑战、六档难度；视觉对齐 24 点。

## 2. 难度（单轴）

| id | 文案 | 网格 | 顺序 | 颜色 |
|----|------|------|------|------|
| `intro` | 入门 | 3×3（1–9） | 正序 1→n² | 单色 |
| `simple` | 简单 | 4×4（1–16） | 正序 | 单色 |
| `normal` | 普通 | 5×5（1–25） | 正序 | 单色（默认） |
| `hard` | 困难 | 5×5 | **倒序** n²→1 | 单色 |
| `master` | 大师 | 6×6（1–36） | 正序 | 单色 |
| `god` | 大神 | 6×6 | **倒序** 36→1 | 单色 |

说明区三行：`网格大小` / `点击顺序` / `视觉`（本期均为单色）。  
本期不做双色；留二期。

## 3. 模式

| 模式 | 行为 |
|------|------|
| 休闲 | 选难度 → 开玩；可重来（新洗牌）、提示下一个（高亮目标格）；单局计时 |
| 挑战 | 选难度 + 局数 5/10/20 → 全局计时；「稍后再做」将本局挪到队尾，须全部完成；无提示 |

## 4. 交互

1. 洗牌填充 `1…n²`。  
2. 顶栏：下一个目标数、本局/全局计时、进度（挑战）。  
3. 点对：短高亮，目标前进；点错：格子闪错，不重开。  
4. 本局完成：休闲显示用时并可再来；挑战进入下一局或结算。  
5. 返回大厅链接。

## 5. 结算（挑战）

题量 / 完成 / 延后次数 / 总用时 / 平均每局用时（完成局）。

## 6. 集成

- `games_catalog`：`status: ready`  
- 大厅卡片 meta「可玩」  
- 静态页即可，无需后端 API  

## 7. 非目标

双色变体、排行榜、本地最高分持久化（可后期加 localStorage）。
