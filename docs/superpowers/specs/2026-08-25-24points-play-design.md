# 24 点游玩页设计

**日期:** 2026-08-25  
**状态:** 已实现  

## 目标

独立静态页 `play.html`（24 点挑战）：休闲模式随机出题；挑战模式可选 5/10/20 题并计时，结束后统计。

## 模式

| 模式 | 行为 |
|------|------|
| 休闲 | 先选难度再出题；可下一题、看参考解；不计时 |
| 挑战 | 先选难度与题量（5/10/20）；计时；「稍后再做」仅把本题挪到队尾，仍须全部完成 |

难度六档与算法见 [2026-08-25-24points-difficulty-design.md](./2026-08-25-24points-difficulty-design.md)。

## 作题交互

1. 四叶草展示当前可用数字（初始 4 个，合并后减少）。
2. 点数字 → 点 `+ − × ÷` → 再点数字 → 合并为新数（整数整除，不可除以 0）。
3. 用尽后只剩一个数且为 24 → 本题完成。
4. **退出**：回模式选择（挑战可确认）。**重来**：重置本轮。**上一步**：撤销合并。

## 题库与构建

- 从 `solutions.txt` 抽取有解四元组 + 一条参考解。
- `generate_play.py` 产出 `output/play.html` 与 `dist/web/games/24points/play.html`。
- `scripts/build.bat` 同时构建解法库页与游玩页。

## 命名说明

游玩页文件名为 `play.html`（相对解法库 `library.html`）。曾用 `quiz.html`，仅为「出题页」的临时英文名，已废弃。
