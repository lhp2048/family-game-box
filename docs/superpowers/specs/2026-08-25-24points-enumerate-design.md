# 24 点穷举（整数运算）设计

**日期:** 2026-08-25  
**状态:** 待实现

## 1. 目标

编写 Python 脚本，穷举数字范围 `0~24`（含端点）、有放回选取 4 个数，使用加减乘除且**每步中间结果均为整数**的运算，找出所有能使结果等于 `24` 的解法，并将汇总与解法写入文件。

## 2. 规则

| 项 | 约定 |
|---|---|
| 数字范围 | `0` 到 `24`（含） |
| 选数方式 | 有放回，允许重复（如 `8,8,3,3`） |
| 运算 | `+` `-` `*` `/` |
| 整除 | `/` 仅当 `b != 0` 且 `a % b == 0` 时合法 |
| 目标 | 最终结果恰好为 `24` |
| 组合归一 | 四元组按升序视为同一组：`(3,8,3,8)` ≡ `(3,3,8,8)` |
| 不交换运算 | 减法、除法两侧顺序都要枚举 |

中间结果可为负数或 `0`，只要整除规则满足且最终为 `24`。

## 3. 算法：递归二分合并

1. 枚举所有升序四元组 `(a,b,c,d)`，满足 `0 ≤ a ≤ b ≤ c ≤ d ≤ 24`。
2. 对每个四元组，取其所有不重复排列，进入求解器。
3. 求解器维护「当前数值列表」与「对应表达式字符串列表」：
   - 仅剩 1 个值：若等于 `24`，则记录该表达式。
   - 否则枚举任意两个下标 `i < j`，对四种运算生成新值与新表达式（形如 `(left op right)`），与剩余项合并后递归。
4. 同一升序四元组下的表达式用集合去重。

该递归自然覆盖所有括号结构（含 `(a op b) op (c op d)` 形态）。

## 4. 输出

```
24points/
  solve_24.py
  output/
    summary.txt
    solutions.txt
```

### 4.1 `summary.txt`

- 数字范围与规则简述
- 升序四元组总数
- 有解组合数 / 无解组合数
- 解法表达式总条数
- 运行耗时

### 4.2 `solutions.txt`

仅写入有解组合。每组格式：

```
[3, 3, 8, 8]  (N solutions)
  (8/(3-(8/3)))
  ...
```

无解组合不写入本文件（仅在 summary 中统计）。

## 5. 脚本接口

```bash
python solve_24.py
python solve_24.py --min 0 --max 24 --out output
```

| 参数 | 默认 | 含义 |
|---|---|---|
| `--min` | `0` | 数字下界 |
| `--max` | `24` | 数字上界 |
| `--out` | `output` | 输出目录 |

依赖：仅 Python 标准库（`itertools`、`argparse`、`pathlib`、`time`）。

## 6. 非目标

- 不支持分数中间结果
- 不做 GUI / Web
- 不强制写入无解组合明细
- 不引入第三方依赖

## 7. 成功标准

- 对整数有解组（如 `4,4,4,4`、`1,2,3,8`）能输出合法整数解
- 注：`3,3,8,8` 的经典解依赖中间分数，在本规则下无解（属预期）
- `summary.txt` 与 `solutions.txt` 按上述格式生成
- 全量 `0~24` 可在合理时间内跑完（约数分钟量级，视机器而定）
