# 数字 / 汉字划销设计

**日期:** 2026-08-26  
**状态:** 实现中

## 目标

独立静态页 `cancel.html`：在随机数字矩阵或汉字矩阵中，快速找出并标记全部目标（如所有的「7」或指定汉字）。训练视觉搜索与细节捕捉能力。

## 内容类型

| 类型 | 填充物 | 目标示例 |
|------|--------|----------|
| 数字 | 0–9 随机 | 单个数字「7」；或多个目标「3」「7」 |
| 汉字 | 常用字表随机 | 单个「的」；或多个高频字 |

字表 MVP：300–500 常用字 JSON；目标字默认「的、一、是、在、不、了、有、和、人、这」等。

## 难度

| 级别 | 矩阵 | 目标占比 | 目标个数 |
|------|------|----------|----------|
| 简单 | 10×10 | 10%–12% | 1 个目标类型 |
| 中等 | 14×14 | 8%–10% | 1–2 个 |
| 困难 | 18×18 | 6%–8% | 2–3 个 |

## 模式

| 模式 | 行为 |
|------|------|
| 休闲 | 随机一题；找齐或点「完成」；可下一题 |
| 挑战 | 连续 5 / 10 题；累计用时；误点扣分或冻结 |
| 限时 | 60s 内完成尽可能多的题 |

## 作题交互

1. 网格展示字符/数字；顶部显示「请找出所有的：7」或目标字列表。
2. 点击一格：若为目标且未标记 → 标记（变灰/打勾/划线），正确数 +1。
3. 点击非目标 → 误点 +1；挑战模式冻结 0.5s 或 -5 分。
4. **完成**：玩家点「完成」→ 若仍有未找目标，提示剩余个数；找齐则自动进入结算/下一题。
5. **重来**：同一 seed 重置标记。

## 生成逻辑

1. 生成 `rows × cols` 随机填充。
2. 随机选取 `target_count` 个位置放入目标字符。
3. 其余位置填充非目标字符（数字模式避免与目标混淆的可选过滤：如目标为 7 时邻格仍可为 7，属正常难度）。
4. 记录 `targets: [[r,c],...]` 供判定（不暴露给前端明文时可仅 hash 校验，MVP 可内联供离线）。

## 题库与构建

- `generate_cancel.py`：嵌入字表与 HTML；运行时 JS 按 seed 生成矩阵。
- 产出 `output/cancel.html`、`dist/cancel.html`。

## 结算指标

- 单题用时、总用时
- 目标总数、正确标记数、漏划数、误点次数
- 搜索效率：正确标记数 / 用时（个/秒）

## 非目标

- 不做手写圈选轨迹识别（首期点击即可）。
- 不做整篇短文划销（二期可扩展为流式排版）。

## 成功标准

- 数字模式 10×10 一题可找齐并结算。
- 汉字模式可切换目标字并完成一题。
- 挑战 5 题连做可显示汇总。
