# Simon Says（老师说）设计

**日期:** 2026-08-26  
**状态:** 实现中

## 目标

独立静态页 `simon.html`：播放或显示指令，**仅当指令以「老师说」开头时**才执行对应动作；否则保持不动。训练听觉（或阅读）专注力与冲动控制。

## 规则

| 试次类型 | 指令示例 | 正确反应 |
|----------|----------|----------|
| 有效 | 「老师说：举手」 | 在反应窗内按下「举手」 |
| 无效 | 「举手」 | **不做任何动作** |
| 有效（口语） | 「老师说，向右转」 | 向右转 |
| 无效 | 「老师说举手」（无冒号/分隔） | 按配置视为无效（默认无效，避免歧义） |

### 变体（分入口）

| 变体 | 规则 |
|------|------|
| 经典 | 有「老师说」→ 做；无 → 不动 |
| 反向 | 有「老师说」→ **不做**；无 → 做 |
| 混合 | 每 N 题切换规则（高阶，二期） |

## 动作库

| 动作 ID | 中文 | 桌面键 | UI 按钮 |
|---------|------|--------|---------|
| hands_up | 举手 | W / ↑ | ↑ |
| hands_down | 放下 | S / ↓ | ↓ |
| turn_left | 向左转 | A / ← | ← |
| turn_right | 向右转 | D / → | → |
| jump | 跳 | Space | 跳 |
| squat | 蹲 | Shift | 蹲 |

无效试次：任何按键/点击均算「冲动错误」（除非超时未动，记正确）。

## 模式

| 模式 | 行为 |
|------|------|
| 休闲 | 单题练习；显示对错与规则解析；无限下一题 |
| 挑战 | 20 / 30 / 50 试次；无效试次比例随难度 30%→50%；结束后统计 |
| 儿童 | 反应窗加长至 4s；语速慢（TTS rate 0.8） |

## 回合流程

1. **呈现**：文字大号显示指令；可选 `speechSynthesis` 朗读（中文 voice）。
2. **反应窗**：2.5s（儿童 4s）；玩家可点动作钮或按键。
3. **判定**：
   - 有效 + 正确动作 → 正确
   - 有效 + 未做 / 错动作 → 遗漏/错误
   - 无效 + 未动 → 正确
   - 无效 + 任何动作 → **冲动错误**
4. 反馈 800ms 后进入下一试次。

## 试次生成

```text
trial = {
  prefix: true | false,     // 是否含「老师说」
  action: "turn_right",
  text: "老师说：向右转",
  valid: true               // 语义上是否应执行 action
}
```

- 无效试次：随机 action，文本仅为「向右转」等，无合格前缀。
- 挑战：有效/无效比例可配置；动作均匀随机。

- `generate_simon.py` 产出 HTML + 内联 JS（指令模板、动作映射、TTS 封装）。
- 产出 `output/simon.html`、`dist/simon.html`。

## 结算指标

- 正确率 = 正确试次 / 总试次
- **冲动错误率** = 无效试次中误动 / 无效试次总数
- 有效试次遗漏率
- 平均反应时（仅有效且正确试次）
- 最长连击

## 非目标

- 不做摄像头姿态识别（首期仅按钮/键盘）。
- 不做多人房间、不做教师端控场。

## 成功标准

- 经典模式 20 试次（约 40% 无效）可完成并区分冲动错误。
- TTS 开关可用；关闭时仅文字仍可玩。
- 挑战 30 试次结算页指标完整。
