# 找不同（Spot the Difference）设计

**日期:** 2026-08-26  
**状态:** 实现中

## 目标

独立静态页 `spot_diff.html`：对比左右（或上下）两幅内容，找出全部差异位置。训练细致观察力与系统性视觉扫描。

## 内容形式（分期）

| 阶段 | 形式 | 说明 |
|------|------|------|
| MVP | 符号矩阵 | 两列相同大小的字符网格，若干格不同 |
| 二期 | 数字/汉字行 | 两段相似文本，差若干字 |
| 三期 | 插画双图 | 需静态资源，点选差异区域（多边形 hit test） |

本文档以 **符号矩阵 MVP** 为验收范围。

## 差异类型（MVP）

| 类型 | 示例 |
|------|------|
| 换字符 | 左 `7` 右 `9` |
| 换颜色 | 同字不同 `color` |
| 换字号 | 同字 `font-size` 略大（可选） |

每题差异位置 5–12 处，左右对称索引 `(r,c)`。

## 难度

| 级别 | 网格 | 差异数 |
|------|------|--------|
| 简单 | 8×8 | 3–5 |
| 中等 | 12×12 | 6–8 |
| 困难 | 16×16 | 9–12 |

## 模式

| 模式 | 行为 |
|------|------|
| 休闲 | 随机一题；找齐或提示；下一题 |
| 挑战 | 5 / 10 题连做；累计用时与误点 |
| 限时 | 90s 内完成尽可能多的题 |

## 作题交互

1. 左右并排两网格（小屏可上下叠放，滚动同步）。
2. 点击任一侧格子：若 `(r,c)` 为差异且未揭示 → 两侧同步高亮（圈选/底色），已找到 +1。
3. 点击非差异 → 误点 +1；挑战模式冻结 1s。
4. **提示**：随机揭示一处未找到差异（每题限 2 次，挑战限 1 次）。
5. **完成**：全部差异找到后自动结算；或点「提交」显示漏找数。

## 生成逻辑

1. 生成 `base[rows][cols]` 随机字符（数字 0–9 或汉字子集）。
2. 随机选 `diff_count` 个坐标，生成 `left`、`right`（仅在这些格 mutate）。
3. 记录 `diffs: [[r,c], ...]` 供判定。

## 题库与构建

- `generate_spot_diff.py`：HTML + 内联 JS 生成器。
- 产出 `output/spot_diff.html`、`dist/spot_diff.html`。
- 与 `cancel.html` 共享网格渲染组件（实现阶段抽公共 CSS/JS 可选）。

## 结算指标

- 单题用时、误点次数、提示次数
- 挑战总用时、完成题数
- 平均发现速度：差异数 / 用时

## 非目标

- MVP 不含插画资源与像素级 diff 算法。
- 不做玩家自定义上传图片。

## 成功标准

- 12×12、6 处差异的一题可全部找到并结算。
- 误点与提示逻辑符合上表。
- 挑战 5 题可显示汇总页。
