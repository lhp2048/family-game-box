# 迷宫（Maze）设计

**日期:** 2026-08-26  
**状态:** 实现中

## 目标

独立静态页 `maze.html`：在网格迷宫中从起点走到终点。训练路径预判、视觉追踪与持续专注。

## 规格

| 级别 | 网格（奇数边长） | 预估用时 |
|------|------------------|----------|
| 入门 | 9×9 | 30–60s |
| 标准 | 15×15 | 1–2min |
| 挑战 | 21×21 | 2–4min |
| 大师 | 31×31 | 5min+ |

迷宫为**完美迷宫**（任意两点间唯一路径），除非开启「多通路」选项（二期）。

## 模式

| 模式 | 行为 |
|------|------|
| 休闲 | 随机迷宫；到达终点或放弃；可「新迷宫」 |
| 挑战 | 连续 3 / 5 关，难度递增；总计时；碰墙计数 |
| 每日一关 | `seed = YYYYMMDD` 固定当日迷宫（可选入口） |

## 作题交互

### 操作方式（可切换，默认点击步进）

| 方式 | 说明 |
|------|------|
| 点击步进 | 点击与当前格四邻且为通道的格移动 |
| 拖动 | 手指/鼠标沿通道拖，碰墙则不计步或回退 |
| 键盘 | 方向键 / WASD（桌面） |

### 规则

1. 起点：左上角通道格；终点：右下角通道格（生成时保证可达）。
2. **碰墙**：拖动模式撞墙 → 碰墙次数 +1；挑战模式每次 +0.5s 惩罚（可配置）。
3. **步数**：每次合法移动 +1。
4. 到达终点 → 本题完成，展示步数、用时、碰墙次数、路径效率。

**路径效率** = 玩家步数 / BFS 最短步数（生成时预计算 `shortestSteps`）。

## 生成算法

1. **递归回溯**或 **Prim** 在 `rows×cols` 网格上 carve 通道（墙为 cell 边或 cell 本身，实现统一即可）。
2. 确保起点、终点在通道上且连通。
3. BFS 求最短步数写入关卡元数据。
4. 输出：`{ rows, cols, walls|grid, start, end, shortestSteps, seed }`。

渲染：Canvas 或 SVG；移动端优先 Canvas + 触控。

## 题库与构建

- `generate_maze.py` 产出 HTML 模板 + 迷宫生成 JS（或预生成少量示例关）。
- 产出 `output/maze.html`、`dist/maze.html`。

## 结算指标

- 完成时间、步数、碰墙次数
- 路径效率比
- 挑战模式：各关明细 + 总用时

## 非目标

- 不做 3D 迷宫、不做多人竞速。
- 首期不做「迷雾」或「限时缩圈」机制。

## 成功标准

- 15×15 迷宫可点击走通并显示结算。
- BFS 最短步数与玩家步数可比。
- 挑战 3 关难度递增可完成。
