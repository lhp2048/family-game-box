# 游戏大厅统一主题设计

**日期:** 2026-09-01  
**状态:** 已确认（范围 B · 气质轻竞技 · 方案 1 共享主题 CSS）  
**产品:** family_game_box

## 1. 目标

将大厅、游戏排行、挑战排行、每日挑战壳页、各游戏首页/选难度页统一为「轻竞技游戏大厅」观感；进出游戏连续，排行强调名次，全家可读。

## 2. 范围

### 2.1 做

| 表面 | 改动 |
|------|------|
| `web/css/fgb-theme.css` | 新增：色板、背景、顶栏、卡片、按钮、榜单、空态、徽章 |
| `web/index.html` | 大厅：品牌首屏、统一顶栏、游戏网格、每日挑战突出卡 |
| `web/leaderboard.html` | 游戏排行：顶栏、胶囊 Tab、前三徽章、本人行高亮 |
| `web/daily-leaderboard.html` | 挑战排行：同上语言 |
| `web/daily.html` | 挑战壳：准备/HUD/结算面板 + iframe 嵌套 |
| `web/admin.html` | 跟主题色与面板（不改信息架构） |
| 各游戏首页/选难度 | 经 `game_common` / 舒尔特 / 24 点注入主题；模式与难度控件套主题类 |
| 对局区 | 仅边框/按钮色对齐；布局与玩法不变 |
| 24 点解法库 | 背景与顶栏轻贴皮 |
| 构建 | `build.bat` / 打包复制 `web/css/` |

### 2.2 不做

- 玩法逻辑、API、难度配置
- 对局内棋盘/手势大改版
- 新插画资源包
- 解法库内容区重设计

## 3. 视觉系统

### 3.1 气质

轻竞技大厅：更深背景、清晰分区、排行强调名次；仍适合家庭场景。

### 3.2 令牌（`fgb-theme.css`）

| 令牌 | 用途 |
|------|------|
| 背景 | 深炭绿渐变 + 极淡网格/光斑 |
| `--ink` / `--muted` | 近白主字 / 次要灰绿 |
| `--accent` | 青绿强调（按钮、链接、本人行） |
| `--panel` | 半透明深面板 |
| `--line` | 低对比描边 |
| `--warn` | 每日挑战暖色 |
| `--gold` / `--silver` / `--bronze` | 排行前三 |
| 字体 | 标题展示字体 + 清晰正文字体（非系统默认堆栈） |
| 圆角 | 卡片 16–20px；胶囊 999px |
| 动效 | 卡片悬停上移约 2px + 边框变亮 |

禁止：紫粉渐变、旧奶油纸风、报纸排版、过亮霓虹。

## 4. 页面结构

### 4.1 统一顶栏

- 左：品牌「家庭游戏盒」+ 当前页短标题  
- 右：昵称 chip · 挑战榜 · 游戏排行 ·（非大厅显示「回大厅」）  
- 底部分割用 `--line`

### 4.2 大厅

- 品牌大字 + 一句 lead（不堆统计）  
- 网格：每日挑战卡暖金边 +「今日」徽章；其余统一面板  
- 底部保留小号管理入口  

### 4.3 排行榜（游戏 / 挑战）

- 同顶栏 + 标题区  
- Tab / 筛选用胶囊  
- 前三金/银/铜徽章；本人行 accent 浅底  
- 空态居中引导  

### 4.4 每日挑战壳

- 准备 / 结算：主题面板  
- 对局：HUD + 圆角 iframe，同大厅背景  

### 4.5 游戏首页 / 选难度

- 同背景 + 同顶栏（回大厅）  
- 模式/难度控件用主题卡片与胶囊  
- 对局区布局与交互不变  

## 5. 落地方式

1. 新增 `web/css/fgb-theme.css`  
2. 可选 `web/js/fgb-shell.js` 统一顶栏标记（或各页手写同一 class 结构）  
3. 壳页改 class 并 `<link>` 主题  
4. `games_common.build_page` / `inject_standalone_overlays` / 舒尔特 / 24 点链入主题  
5. 重新生成 `web/games/**`  
6. 构建脚本复制 `web/css/`
