# 24 点出题页设计

**日期:** 2026-08-25  
**状态:** 实现中

## 目标

独立静态页 `quiz.html`：休闲模式随机出题；挑战模式可选 5/10/20 题并计时，结束后统计。

## 模式

| 模式 | 行为 |
|------|------|
| 休闲 | 随机有解题；可下一题、看参考解；不计时 |
| 挑战 | 开局选 5/10/20；计时；做完或退出后结算（完成/跳过/用时） |

## 作题交互

1. 四叶草展示当前可用数字（初始 4 个，合并后减少）。
2. 点数字 → 点 `+ − × ÷` → 再点数字 → 合并为新数（整数整除，不可除以 0）。
3. 用尽后只剩一个数且为 24 → 本题完成。
4. **退出**：回模式选择（挑战可确认）。**重来**：重置本轮。**上一步**：撤销合并。

## 题库与构建

- 从 `solutions.txt` 抽取有解四元组 + 一条参考解。
- `generate_quiz.py`（或扩展生成器）产出 `output/quiz.html` 与 `dist/quiz.html`。
- `scripts/build.bat` 同时构建解法库页与出题页。
