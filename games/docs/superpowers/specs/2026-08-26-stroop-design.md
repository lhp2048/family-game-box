# Stroop 效应（色字干扰）设计

**日期:** 2026-08-26  
**状态:** 实现中

## 目标

独立静态页 `stroop.html`：呈现「字义与字体颜色不一致」的经典认知任务。玩家需快速选择**字的颜色**（而非读字）。训练抗干扰能力与选择性注意力。

## 刺激材料

| 项 | 约定 |
|----|------|
| 字（中文） | 红、黄、蓝、绿、黑、白、紫、橙（8 种，可扩展） |
| 颜色 | 与字义同名 8 色，色值固定映射 |
| 不一致试次 | 字义 ≠ 字体颜色 |
| 一致试次 | 字义 = 字体颜色（约 20%，作基线） |

## 模式

| 模式 | 行为 |
|------|------|
| 休闲 | 无限随机试次；即时对错反馈；不计时 |
| 挑战 | 60s / 120s 限时，或固定 30 / 50 试次；结束后统计正确率、平均反应时、Stroop 干扰量 |
| 反向（可选） | 任务改为「读字义、忽略颜色」；与经典模式分入口 |

**Stroop 干扰量** = 不一致试次平均 RT − 一致试次平均 RT（仅统计正确试次）。

## 作题交互

1. 屏幕中央显示一个大号 colored 汉字。
2. 顶部固定任务条：「请选字的颜色，不要读字」。
3. 底部 4–8 个颜色按钮（或与当前字库匹配的子集）；点选即提交。
4. 记录 `performance.now()` 自刺激呈现至点击的 RT。
5. 反馈：正确短暂绿框；错误红框 + 显示正确答案。
6. 休闲模式自动下一题；挑战模式无间隔或固定 300ms 间隔。

## 试次生成

```text
trial = {
  word: "蓝",           // 字义
  ink: "red",           // 实际颜色
  congruent: false,     // word 与 ink 是否一致
  choices: [4~8 色按钮，含唯一正确答案 ink]
}
```

- 不一致：随机 word，随机 ink ≠ word 映射色。
- 一致：word 与 ink 对应。
- 挑战模式内一致/不一致比例可配置（默认 2:8）。

## 题库与构建

- 逻辑纯前端即可；`generate_stroop.py` 仅产出 HTML 壳 + 内联 JS（与 `generate_quiz.py` 同构）。
- 产出 `output/stroop.html`、`dist/stroop.html`。

## 结算指标

- 正确数 / 总试次、正确率
- 平均 RT（全体、一致、不一致）
- Stroop 干扰量（ms）
- 最长连击

## 非目标

- 不做语音作答（首期仅点选）。
- 不做 ERP / 外设采集。

## 成功标准

- 经典模式下 20 试次可连续完成并区分一致/不一致 RT。
- 挑战 60s 模式可正常结束并展示结算页。
